Как подготовить MikroTikГруппа, пользователь, SSH и firewall

⌄
  1. Откройте Terminal в WinBoxКоманды нужно выполнить от администратора устройства.
  2. Создайте отдельную группу и пользователяПрава ограничены SSH, файлами, чтением и созданием backup/export.
/user group add name=routervault policy=ssh,ftp,read,write,sensitive
/user add name=routervault group=routervault password="ЗАМЕНИТЕ_НА_СЛОЖНЫЙ_ПАРОЛЬ"
/ip service set ssh disabled=no port=22
!

Ограничьте доступ к TCP/22В firewall разрешите SSH только с IP-адреса сервера RouterVault. Не открывайте порт для всего интернета.

Если SSH работает на другом порту, укажите его и на MikroTik, и в поле ниже. Встроенные группы read/write/full использовать не рекомендуется — у них больше прав.

⌾

Локальное шифрованиеПароль шифруется мастер-ключом и не возвращается в браузер.
